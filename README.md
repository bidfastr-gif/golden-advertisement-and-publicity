# Golden Advertising & Publicity Website

This project is a modern, premium website redesign for **Golden Advertising & Publicity**, featuring a "Golden" aesthetic with smooth animations and interactive elements.

## Features

*   **Premium Design**: Black & Gold color palette with elegant typography (Outfit & Inter).
*   **Smooth Animations**: Powered by **GSAP** (ScrollTrigger) and **Lenis** (Smooth Scrolling).
*   **Interactive Elements**: 
    *   Magnetic Buttons
    *   Infinite Marquee
    *   Scroll-triggered text reveals
    *   Animated counters
*   **Responsive**: Fully responsive layout for all devices.

## Setup & Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Customization

*   **Content**: Edit `index.html` to update text and images.
*   **Styles**: Edit `style.css` to tweak colors or layout.
*   **Animations**: Edit `main.js` to adjust animation timing or effects.
